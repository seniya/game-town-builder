## 측정 (MVP_SPEC 36 조건, headless)

기준 장치: Linux 6.17, NVIDIA GeForce GTX 1070, Chrome 148(`--headless=new`, ANGLE Vulkan), `vite preview`, 1280 × 720, DPR 1.
워밍업 뒤 60 초. headless 는 수직 동기 60 에 묶여 여유를 보여 주지 않는다(실제 창 확인은 V2 Q9).

- 드로우콜은 그림자·후처리 패스를 합산한 값이다(STYLE-005 부터). 모두 36 장의 600 미만이다.
- 사람은 한 명 3 드로우콜(본체·외곽선·그림자), 가구는 종류마다 3 이라 주민·가구 수가 늘어도 드로우콜이 거의 늘지 않는다.
  큰 마을(X3)에서는 청크 그림자 패스와 먼 사람·가구의 컬링·단순 모형이 다음 병목 후보다(ADR 046·047).

## 확인하지 못한 것

- 점심 식당에서 의자에 앉은 모습, 몬스터 습격 장면(레벨 2·밤)은 headless 에서 만들지 못했다. V2 장면 3·5 로 넘겼다.
- 실제 창 FPS, 약한 GPU 에서의 `quality=low` 필요 여부.
