# 공간의 아름다움과 주민의 생활을 핵심 목표로 강화

Date: 2026-09-22
Status: 문서 반영 완료 — 구현·플레이 검증 미착수

## 반영 내용

사용자 요청에 따라 게임의 최우선 목표를 다음과 같이 명시했다.

> 아름답게 만든 공간에서 정감 있는 주민이 실제로 살아가는 순간

- `GAME_DESIGN.md`: 공간을 가꾸는 즐거움, 주민에 대한 애착, 일상이 이어지는 장면을
  목표로 구체화했다. 방 인식은 생활로 이어지는 약속이며, 귀가·취침·기상을 관찰하는
  순간에 보상이 완성되도록 감정 흐름·연출·그래픽·의사결정·성공 기준을 맞췄다.
- `README.md`, `MVP_SPEC.md`: 같은 목표와 기존 콘텐츠를 통한 표현 방향을 반영했다.
  아름다움은 플레이어의 감상이며 별도 점수나 방 판정 조건으로 추가하지 않는다.
- `TASKS.md`: TASK-022에 공간을 더 가꾸고 싶은지, TASK-033에 주민과 공간이 정겹고
  아침의 일상을 다시 보고 싶은지 확인하는 질문과 관찰 기록 지침을 추가했다.
- `AGENTS.md`, `TASKS.md`: 항상 작업 완료 후 해당 변경을 commit·push하고 원격 반영을
  확인하도록 작업 절차를 명시했다. 기존 사용자 변경은 임의로 포함하지 않는다.

수치·조건식·인터페이스·Task 의존 순서의 변경이나 새 게임 시스템 추가는 없다.
기술 구조 결정이 아니므로 별도 ADR은 추가하지 않았다.

## 검증

- 문서 diff와 Markdown 형식·로컬 링크·장 참조를 확인했다.
- 기존 명세 검증 스크립트에서 53개 Task와 선행 조건, 공간 판정 예시,
  자원·시간 수치 검산, 자정 전후 nightId 검증이 통과했다.
- `git diff --check`를 통과했다.
- 구현 코드가 없는 문서 작업이다. 브라우저 검증이나 재미 검증을 완료한 것은 아니다.
