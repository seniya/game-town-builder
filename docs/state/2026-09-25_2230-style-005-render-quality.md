## 찾은 것

- **MSAA 렌더 타깃 + 빛 번짐 = 검은 화면.** 빛 번짐은 결과를 읽기 버퍼에 더해 그리는데, MSAA 버퍼는 해상(resolve) 뒤 내용이
  무효화되어 화면 전체가 깨졌다(headless 에서 MSAA 끄기만으로 해결됨을 확인). MSAA 대신 SMAA 를 쓴다.
- 색 보정 단계가 입력의 알파를 그대로 내보내 캔버스가 투명해지고 페이지 배경이 비쳤다. 항상 알파 1 로 내보낸다.
- headless Chrome 은 시작 때 가끔 WebGL 컨텍스트를 잃고 되찾는다(이전 기준 촬영에서도 있었다). 되찾은 뒤에는 정상으로 그렸다.
