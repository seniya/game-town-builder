## 무엇을 했는가

사용자의 “검토한 내용으로 문서를 업데이트” 요청에 따라 네 정본을 v1.1로 갱신했다.
README, 관련 ADR, 조사 기록의 불확실성 표기도 함께 맞췄다.
새 블록·가구·역할·자원·프레임워크는 추가하지 않았다.

주요 수치·정책 선택:

- 잎은 leaves 1개 회수 + seed 25% 추가 드롭. 반복 배치에도 같은 규칙.
- 화덕·물통은 레벨 1. 레벨 2 해금은 window / chest.
- 성장 3단계 각각 4시간, 12시간에 성숙. 초기 밭 4칸 → 확장 8칸.
- 단계별 종 비용 80 / 200, 총 280.
- 기존에 의도만 있던 피해 상한을 습격당 16복셀로 명시. 수리는 하루 8복셀.
- 첫 방 10~20분, 첫 취침 20~30분을 측정 목표로 삼음. 최종 분량 90~120분은 가설.
- Vite 8 유지, Vitest 4.1 이상 4.x로 공식 지원 조합을 선택.

## 검증

임시 Python 검증과 git diff --check를 수행했다.

- 현재 정본의 Markdown 코드 펜스, 로컬 링크, 수치형 장 참조 확인.
- TASK 53개가 중복·누락 없이 실행 순서에 들어가는지 확인.
- 모든 명시적 선행 Task가 실제 실행 순서에서 앞에 있는지 확인. 의존 순환 없음.
- 작은 평지 방에서 빈 방·가구 포함 방이 모두 내부 25칸으로 성공하는 규칙을 검산.
- 벽 구멍의 TOO_LARGE와 둘째 층 벽의 WALL_TOO_LOW, 먼 편집의 문 후보 포함을 검산.
- 12시간 성장, 밭 4/8칸의 음식 6/12개, 단계 비용 총 280, 첫 방 재료 59/67판자를 검산.
- 같은 재질·AO의 두 블록에서 단위 면 10 → 병합 쿼드 6 계산을 확인.
- 자정 전후 nightId가 같고 다음 밤에는 달라지는 예를 확인.

위 검증은 명세 자체의 작은 반례·산술 검증이다.
구현 코드와 package.json이 없으므로 pnpm test/build 및 브라우저 검증은 하지 않았다.
Task 체크박스를 완료로 바꾸지 않았다.
