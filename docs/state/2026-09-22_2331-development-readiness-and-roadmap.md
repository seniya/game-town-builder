# 개발 준비 점검과 전체·세부 로드맵 보완

Date: 2026-09-22
Status: 문서 작업 완료 — 게임 구현·브라우저·재미·성능 검증 미착수
검토 기준: 458f282

## 판단

**TASK-001은 착수 가능하며, 전체 개발을 무조건 착수 가능으로 판정하지 않는다.**
핵심 4문서를 지정 순서로 읽고 README·문서 안내·현재 AGENTS, 직전 검토의 열린 정책,
ADR 017~020과 기존 툴체인 조사 기록을 대조했다. 기존 작업 트리는 깨끗했다.
게임 코드·package.json·lockfile은 없으며 55개 구현 Task는 모두 미착수다.

기존에 A~I 전체 단계와 일반 53개·PERF 2개의 세부 Task가 있었다. 실행 순서의 누락·
중복·선행 의존 오류는 발견되지 않았다. 로드맵 자체가 없었던 것으로 판단하지 않는다.
부족했던 것은 단계별 결과를 모은 안내, 미결정 정책의 현재 관리 위치, 후속 통합 검증과
실제 플레이 관찰을 남길 공통 형식이었다.

## 변경 사항

- [ROADMAP](../project/ROADMAP.md)을 추가했다. 준비 상태, 단계별 시작 조건·결과,
  두 재미 검증, 최종 슬라이스 검증, 예상 작업량을 다시 추정할 시점을 정리했다.
- MVP 이후 10명→50명 중간 검증→100명·대형 마을의 조건부 계획을 작성했다.
  장기 콘텐츠·성능 기준을 지금 확정하거나 새 구현 Task로 추가하지 않았다.
- [TASKS](../project/TASKS.md) 2.5에 도구 검증과 미결정 정책의 담당·확정 기한·정본·
  검증 계획을 모았다. 기존 지지면/모달/채석장/전투 항목에 물·월드 경계·발판 상실과
  F 상호작용 선택의 미확정 사항을 추가했다. 정책의 구체 동작은 해당 Task 전에 정한다.
- TASKS 2.6에 통합 테스트 10개를 실제 연결 Task와 매핑했다. 초기 진단·취침 검증과
  이후 포인트/기부/습격/저장 연동을 구분하고 마지막에는 053에서 전부 재실행한다.
- TASKS 2.7에 첫 Phase의 9개 실행 순서별 정본 참조와 결과물을 정리했다.
  006의 화면 AC가 아직 없는 007의 Renderer를 필요로 하므로 최소 장면을 006에서
  연결하고 007에서 완성하도록 명시했다. 재질 소유권과 실행 순서는 유지한다.
- 기존 명세의 Esc 메뉴에 구현 담당이 명확하지 않아 TASK-015에 모달 입력과 함께
  배정했다. 시간 정책은 READY-03에서 먼저 정하고, 새 메뉴 기능은 추가하지 않았다.
- TASK-048의 “기록에서 제거”를 미수리 목록 해제로 한정했다. 기존 MVP_SPEC 25와
  ARCHITECTURE 19에 따라 아침 보고용 피해 이력은 보존한다.
- TASKS 4.1에 완료·실제 소요·관찰·시스템/감성 결과·재검증 기록 형식을 추가했다.
- README와 docs/README에서 전체/세부 계획을 연결하고, MVP_SPEC의 열린 정책 링크를
  과거 state에서 현재 TASKS로 옮겼다.

TASKS만 계획 개정 v1.4로 표시하며 게임 명세 v1.3·수치·콘텐츠·인터페이스는 유지했다.
이번 작업은 기존 결정의 실행 계획과 기록 위치를 보완한 것으로 새 기술 결정은 없다.
따라서 새 ADR은 만들지 않았다. 외부 조사를 수행하지 않았으며 기존 패키지 조사값을
이번 시점에 재확인한 것으로 취급하지 않는다.

## 검증 범위

- 변경 문서 6개의 코드 펜스 짝과 로컬 링크/앵커 24개를 검사해 오류가 없음을 확인했다.
- Task 정의·실행 목록은 각각 55개이며 중복·누락·선행 의존 역전이 없다.
  기준 커밋과 실행 순서·각 Task의 의존 목록도 동일하다.
- 준비 항목 8개와 통합 테스트 1~10의 연결이 중복·누락 없이 존재한다.
- MVP_SPEC 2장 이후의 게임 명세는 기준 커밋과 동일하다. 체크된 AC는 0개이며
  구현 Task를 완료 처리하지 않았다.
- `git diff --check`를 통과했다. 임시 Python 검사만 사용했고 도구 의존성을 추가하지 않았다.

게임 테스트·빌드·브라우저 플레이는 실행 코드가 없고 이번 작업이 개발 전 계획 검토이므로
수행하지 않았다. 어떤 재미 게이트도 완료 처리하지 않았고 성능·분량·재미 달성을 주장하지 않는다.
