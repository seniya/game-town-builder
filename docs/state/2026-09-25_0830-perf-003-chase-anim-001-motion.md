  대상이 바뀌면 이전 요청을 취소한다. 쫓을 대상이 없으면 추적 전 모드(배회 / 종 옆 대기)로 돌아간다(`endChase`).

  main 이 `breakingPos`·`BLOCK_CHANGED`(player, 설치)·`COMBAT_HIT`(monster)를 읽어 넘긴다.
- `MonsterView`: 공격 동작(움츠렸다 달려들기), 부수기·공격 동작 비중 보간.

## headless 관찰

- `?scene=kitchen-lab&view=4`(12 시): 목수가 망치를 든 채 의자에 앉아 먹는다. 식탁·의자 높이는 그대로다.
- `?scene=sleep-lab&residents=1&view=1`: 카메라를 침실 안 모서리에 둔 관찰용 조작(렌더 직전 카메라 고정, 게임 상태는 건드리지 않음)으로 봤다.
  20:00 귀가 → 문 → 침대 옆에서 0.1~0.4 초 사이에 몸을 기울이며 침대 위로 옮겨 눕는다 → 이불·z.
  처음에 지붕 블록을 지워 보려 했더니 방 인식이 풀려 쉬기로 바뀌었다. 그 관찰은 버렸다(월드를 바꾸는 관찰은 하지 않는다).
- `?scene=house`: 서기·점프(팔 들기)·낙하(팔 벌리기)·공격(오른팔 휘두르기). 낙하 때 팔이 안쪽으로 모이는 부호 오류를 찾아 고쳤다.
  headless 에서는 포인터 락이 걸리지 않는다. 그래서 시작 오버레이를 숨기고 플레이어 접지·수직 속도·`COMBAT_HIT` 을 직접 넣어 봤다.
  걷기·파괴 동작은 이 방식으로 보지 못했고 시험으로만 확인했다.
- `?scene=kitchen-lab&view=0`: 기절(stunUntil 을 직접 넣음)한 농부가 고개를 떨구고 주저앉는다. 광장에 앉아 쉬는 자세와 구별된다.
- 수리 동작(목수 망치질)은 피해 장면을 만들지 못해 headless 로 보지 못했다. 시험으로 자세만 확인했고 HR-030 에 넣었다.
