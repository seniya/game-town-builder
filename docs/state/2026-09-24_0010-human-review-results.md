## 기타 의견 1: 블록 모양 — 결정 필요

지금은 침대·문만 렌더 모형(ADR 026)이고 나머지는 모두 1 칸 정육면체다. 제안:

- **범위**: 새 블록을 만들지 않고 **기존 블록의 모양만** 바꾼다. 후보는 torch(막대+불꽃), window(얇은 창틀), table / chair / chest / cooking_stove / water_pot(가구 모양), crop(십자 풀), bell.
  충돌·방 판정·설치 규칙은 그대로다(ADR 026 과 같은 원칙). 반 블록·계단 같은 **새 블록 종류는 MVP_SPEC 38 금지**라 MVP 이후 후보로만 둔다.
- **방식**: 청크 메셔에 "모양 표" (블록 → 상자 몇 개)를 두어 정적인 것은 청크 메시로, 움직이는 것(문)은 지금처럼 모형으로 그린다. ADR 을 먼저 쓴다.
- **시점**: (a) PERF-001 전에 한다 / (b) Phase E(농사·요리·식사) 뒤, 가구를 실제로 쓰는 장면이 생긴 다음에 한다 / (c) MVP 이후.
  추천은 (b): 요리·식사가 붙으면 화덕·식탁·의자 모양이 장면의 중심이 되고, 그때 모양과 사용 자세를 함께 맞출 수 있다.
