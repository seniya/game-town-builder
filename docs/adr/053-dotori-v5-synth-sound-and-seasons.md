# ADR 053. V5 소리와 계절: 브라우저에서 만드는 소리, 28 일 달력의 네 계절과 축제

Status: Accepted
Date: 2026-09-27
Related: ADR 049·052, docs/dotori/SPEC.md 12 장, docs/dotori/TASKS.md 5.3, DESIGN 6
Evidence: [docs/research/2026-09-27-dotori-sound-sources.md](../research/2026-09-27-dotori-sound-sources.md)

## 배경

- 오너는 게임의 재미로 매력적인 그래픽·**아름다운 음악**·몰입되는 플롯을 꼽았다(메모리). 지금 마을은 소리가 전혀 없다.
- VG3 가 통과했다(2026-09-27 오너 기록). 로드맵은 V5(소리·계절)를 V4(큰 마을)보다 앞에 둔다(TASKS 5).
- 마을의 하루는 이미 리듬이 있다(아침 출근·점심 빵집·저녁 주점·밤 불빛). 한 해(28 일)는 생일에만 쓰이고, 날은 모두 같은 풍경이다.

## 결정

1. **소리는 Web Audio API 로 만든다(파일 없음).** 배경음악은 손으로 정한 조·화음 진행·빠르기(`data/music.ts`) 위에서
   8 마디 곡(A A′ B A)을 그때그때 짓고, 부드러운 음색(오르골·마림바·플루트·하프·패드·베이스)과 잔향으로 연주한다.
   환경음(새·풀벌레·비·바람·물·주점 웅성임·망치·도끼)은 잡음과 발진기로 만들고, **마을 상태와 카메라 거리**로 크기를 정한다.
   이유는 조사 문서의 네 가지: 곡마다 라이선스 확인, 제작자마다 다른 음색, 상태 연동, 아티팩트 보기 화면에서 음원 파일 재생 미확인.
2. **새 층 `src/dotori/audio/`** 를 둔다. World 를 읽기만 하고(ui 와 같은 규칙) `three` 를 import 하지 않는다(ESLint).
   곡 짓기(`compose.ts`)와 소리 크기 계산(`mix.ts`)은 순수 함수로 두어 node 에서 시험한다. Web Audio 는 `Sound.ts`·`synth.ts` 에만 있다.
   카메라 위치·거리·방향은 render 가 숫자로 넘긴다.
3. **자동재생 정책**: 첫 누르기·키 입력에서 AudioContext 를 연다. 기본은 켜짐, 🔊 단추로 끄고 음량을 바꾼다. 창이 숨으면 멈춘다.
4. **계절은 28 일 달력을 넷으로 나눈다**(봄·여름·가을·겨울 7 일씩, 생일과 같은 달력). 계절은 **보이는 것과 행사**만 바꾼다:
   땅·나뭇잎 색, 눈·꽃잎·낙엽 입자, 겨울에는 비 대신 눈, 계절 첫날 소식, 배경음 조 옮김.
   작물 성장·먹거리·이사 수치는 바꾸지 않는다(V2.5 에서 맞춘 성장 고리를 흔들지 않는다).
5. **축제는 파티 규칙을 다시 쓴다.** 계절마다 넷째 날 17:00~21:00 광장에서 한 번(봄 꽃잔치·여름 별밤 잔치·가을 수확제·겨울 등불잔치).
   모든 주민이 소식을 알고, 주최는 계절에 어울리는 사람(성격·직업, 없으면 가장 오래 산 주민)이다.
   파티·결혼식이 이미 잡혀 있으면 다음 날로 미룬다. 새 건물·새 자원·새 행동은 없다.

## 검토한 대안

- **CC0 음악·녹음 파일**: 조사 문서 참조. 사람이 합성 음악을 빈약하다고 하면 배경음악만 CC0 곡으로 바꾸는 것을 다음 후보로 둔다.
- **Tone.js 같은 음악 라이브러리**: 스케줄링이 편하지만 새 의존성이고(AGENTS 7 새 프레임워크 금지 취지), 필요한 기능이 작다.
- **계절이 작물을 멈춘다(겨울 휴경)**: 현실감은 있지만 빵 부족 → 이사 감소로 V2.5 고리가 흔들린다. 먼저 보이는 계절만 넣고 사람의 판단을 본다.
- **한 해를 늘린다(계절당 14 일 이상)**: 1× 에서 하루 4 분이라 계절이 56 분이 된다. 한 번 켜 둔 동안 계절 변화를 보기 어렵다.
- **축제를 따로 행사 장소에서**: 새 건물이 필요하다. 광장과 파티 장식을 다시 쓴다.

## 예상되는 결과

- 마을을 켜 두면 시간대마다 음악이 바뀌고, 카메라를 공사장·주점·호수로 옮기면 그곳 소리가 커진다. "살아 있는 마을" 이 귀로도 느껴진다.
- 28 분(1×)마다 계절이 바뀌고, 계절마다 축제가 한 번 열려 신문의 머리기사가 된다.
- 위험: 합성 음악의 품질은 에이전트가 들을 수 없다. 음량·잘림은 headless 에서 OfflineAudioContext 로 재지만 아름다움은 사람이 판단한다(HUMAN_REVIEW).
- 위험: 계절 색을 셰이더로 바꾸므로 나무 에셋의 초록 판정이 어긋나면 줄기까지 물들 수 있다. 캡처로 확인한다.
