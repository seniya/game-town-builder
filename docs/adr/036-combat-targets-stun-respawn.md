# ADR 036. 전투: 공격 대상·차폐·넉백·기절·안전한 부활 (READY-05)

Status: Accepted
Date: 2026-09-24
Basis: MVP_SPEC 9.1 / 19.2 / 24.2 / 24.3 / 26, TASK-046 구현과 테스트. 새 외부 조사 없음.
Related: ADR 015 / 033
Amends: MVP_SPEC 24.2(공격 사거리)·26.1 신설, TASKS 2.5 READY-05, balance(monster.attackRange / attackHeight, combat.knockback, player.respawnGuardSeconds)

## 배경

체력·공격력·간격·기절 시간은 정해져 있었지만 몬스터가 언제 누구를 때리는지, 벽 너머를 때릴 수 있는지, 넉백의 크기,
기절 뒤 체력, 부활 위치의 안전은 비어 있었다(READY-05). 좌클릭이 블록 파괴와 공격을 함께 맡는 것도 구분이 필요했다.

## 결정

1. **플레이어 공격**은 조준 광선(블록 편집과 같은 광선)이 사거리 2.5 안에서 블록보다 먼저 몬스터 몸체에 닿을 때다. 그때 BlockEditSystem 은 파괴를 진행하지 않는다.
   간격 0.5 초, 1 대미지, 넉백 0.3 칸(충돌 이동). 몬스터 체력 3 → 세 대.
2. **몬스터 공격**은 수평 1.2 이하·높이 차 1.5 미만·가슴 높이 선분에 고체가 없을 때 가장 가까운 대상(플레이어, 기절하지 않은 주민). 간격 1.5 초, 2 대미지.
   사거리 밖이면 원래 판단(ADR 015 의 이동·파괴)을 그대로 한다. 종 반경 도달 뒤나 파괴 후보·예산이 없을 때만 반경 12 안의 대상을 추적한다.
3. **주민 기절**: 체력 0 → 30 게임분 동안 판단하지 않고 주저앉는다(IdleAction '기절'). 기절 중에는 대상이 아니다. 깨어나면 체력 10.
4. **플레이어 부활**: 체력 0 → 종 둘레 광장 칸 중 모든 몬스터와 3 칸 이상 떨어진 칸, 없으면 가장 먼 광장 칸. 체력 20, 인벤토리 유지, 3 실초 보호.
   PLAYER_DOWN 을 발행하고 UI 는 열린 모달을 닫는다. 게임 오버는 없다.
5. **CombatSystem**(12 번 슬롯)이 공격 판정·체력 변경·기절·부활을 소유한다. MonsterSystem 은 추적 이동만 한다.

## 검토한 대안

- **벽 너머 공격 허용**: 방 안이 안전하지 않게 되어 "집 안으로 도피"(TASK-047)가 의미를 잃는다.
- **부활 위치 = 시작 위치**: 섬 반대편이면 긴 이동이 벌이 된다. 종 옆은 명세다.
- **기절 중 계속 맞음**: 주민이 반복해서 쓰러져 보이는 장면은 정감 목표와 어긋난다.

## 예상되는 결과

- TASK-047 도피는 위협 판단 우선순위 1 로 사거리 전에 주민을 떼어 놓는다.
- 수치(1.2 / 1.5 / 0.3 / 3 초)는 HR 로 체감을 본 뒤 조정할 수 있다(MVP_SPEC 먼저 개정).
