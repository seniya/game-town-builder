# ADR 045. 시안 모형: 코드 생성 둥근 지오메트리 + 관절별 병합 + 툰 명암·외곽선

Status: Accepted (STYLE-001 시안 범위). 게이트 V1 뒤 STYLE-002~005 에 넓혀 쓸지 다시 본다.
Date: 2026-09-25
Evidence: [2026-09-25 DQB2 보이는 방식 조사](../research/2026-09-25-dqb2-visual-style-and-room-expansion.md)
Related: ADR 044(미술 방향), ADR 041(관절 자세), ADR 026·028(가구 렌더 모형), MVP_SPEC 36·45, 확장 로드맵 X0

## 배경

ADR 044 는 주민·소품을 둥글고 귀엽게 바꾸기로 했고, 외부 3D 에셋(glTF) 도입 여부는 STYLE-001 에서 정하기로 했다.
오너 결정 D3(외부 에셋·글꼴 허용)은 아직 받지 않았다. 지금 주민 모형은 상자 메시 약 20 개(메시마다 드로우콜 1)이고
재질은 Lambert 단색이다.

## 결정

1. **시안은 코드로 만든 지오메트리로 만든다.** 구·캡슐·회전체(Lathe)·둥근 상자(RoundedBox)를 three 기본·예제 모듈로 만든다.
   새 라이브러리·파일 에셋을 넣지 않는다(three 패키지 안의 `examples/jsm` 는 새 의존이 아니다).
2. **관절마다 한 메시로 합친다.** 부품마다 정점 색을 넣고 관절(몸·머리·다리 둘·팔 둘·모자) 단위로 `mergeGeometries` 한다.
   눈은 깜빡임을 위해 두 눈을 한 메시로 따로 두고, 입·볼은 외곽선 없는 얼굴 메시로 둔다. 주민 한 명의 드로우콜은
   외곽선 포함 약 16~18 로, 지금(약 20)보다 늘지 않는다.
3. **재질은 정점 색 툰 명암**(`MeshToonMaterial` + 2·3 단 계단 텍스처)에 **가장자리 밝힘**을 더한다.
   외곽선은 뒷면을 법선 방향으로 부풀린 반전 껍질(inverted hull)이다. 재질 생성은 `materials.ts` 한 곳이다.
4. **블록 시안 텍스처도 코드로 그린다.** 64 px 타일을 픽셀 배열로 결정적으로 칠한다(값 잡음을 몇 단계로 끊은 넓은 색면,
   부드러운 줄눈, 풀 윗면이 옆면으로 흘러내린 물결 가장자리). 선형 필터·밉맵을 쓴다.
5. glTF 도입은 **보류**한다. D3 이 허용되고 V1 에서 코드 생성 모형의 한계(얼굴·옷 주름·머리카락 표현)가 드러나면 다시 본다.

## 검토한 대안

- **외부 glTF 모형**: 형태 표현의 한계가 없고 미술가와 나눠 일하기 쉽다. 그러나 모형을 만들 도구·사람이 이 환경에 없고,
  에셋 저작권·라이선스 확인이 필요하며, 자세 표(ADR 041)와 관절 이름을 맞추는 작업·로더가 더해진다. D3 전에는 쓸 수 없다.
- **부품마다 메시**(지금 방식 그대로 둥근 부품만): 가장 단순하지만 둥근 부품은 수가 많아 주민 한 명이 40~60 드로우콜이 된다.
  100 명 확장(ARCHITECTURE 2.3)에 불리하다.
- **스키닝 메시(뼈대)**: 관절이 이어져 보이지만 코드로 가중치를 만드는 비용이 크다. SD 캐릭터는 관절이 떨어져 보여도 어색하지 않다.
- **후처리 외곽선(깊이·법선 경계 검출)**: 화면 전체에 한 번이라 메시 수와 무관하지만, 렌더 타깃·합성 단계가 더해지고
  블록 세계 전체에 선이 생긴다. 사람·소품에만 선을 주려는 방향(ADR 044 1)과 맞지 않다.

## 예상되는 결과

- 시안과 지금 모형을 같은 조명에서 비교할 수 있고, 등신비·눈·명암 단계·외곽선을 장면 안에서 바꿔 볼 수 있다.
- 합친 지오메트리는 역할별로 한 번 만들어 공유할 수 있다(STYLE-002). 원거리 단순 모형(LOD)은 외곽선을 끄고 관절을 합쳐 만들 수 있다.
- 반전 껍질 외곽선은 드로우콜을 두 배로 만든다. 주민 100 명이면 외곽선만 약 800 이라, 확장 단계에서는 거리에 따라 끄는
  규칙이 필요하다(X3 측정 대상).

## 시안에서 확인한 것 (2026-09-25, STYLE-001)

- 한 명의 드로우콜: 지금 요리사 17, 시안 16(외곽선 끄면 9). 삼각형은 시안 A·B 11 432, C 10 640(지금 상자 모형은 수백).
  삼각형이 크게 늘었다. 100 명이면 약 114 만이라 원거리 단순 모형·분할 수 축소가 필요하다(X3 측정).
- three 표준 재질은 복셀 셰이더보다 약 π 배 어둡게 그려진다. 시안 재질은 π 를 곱해 맞췄다(MVP_SPEC 45.1).
  이 보정 없이는 시안이 회색으로 가라앉아 비교가 공정하지 않았다.
