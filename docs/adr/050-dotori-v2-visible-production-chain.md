# ADR 050. V2 분주한 마을: 눈에 보이는 생산 사슬(밀 → 방앗간 → 빵, 생선 → 주점)

Status: Accepted
Date: 2026-09-27
Related: ADR 049, docs/dotori/SPEC.md 9 장, docs/dotori/TASKS.md 4 장

## 배경

- 게이트 VG1 은 2026-09-27 오너가 "좋다. 다음단계 새 컨텐츠 개발을 진행한다" 고 해 통과했다.
- V1 까지 빵은 매일 아침 24 개가 저절로 채워졌다. 빵이 동나는 사건이 생겨도 이유가 없다.
  길에는 걷는 사람만 있고 무엇을 나르는 사람은 목재뿐이다.
- 오너가 참고로 든 Anno 의 즐거움 상당 부분은 "만든 것이 흐르는 모습" 에서 온다고 본다(제안 문서 3.2, 가설).

## 결정

1. **자원은 네 가지만 더한다: 밀, 밀가루, 빵(이미 있음), 생선.** 화폐·가격·세금은 계속 넣지 않는다(DESIGN 8).
2. 새 건물·새 직업을 만들지 않는다. 이미 있는 **풍차를 방앗간**으로, **주점을 저녁상 자리**로 쓴다. 농부·제빵사·어부의 일을 바꾼다.
3. 재고는 건물에 둔다(방앗간: 밀·밀가루, 빵집: 밀가루·빵, 주점: 생선). 사람이 등짐으로 나른다. 사람이 나르지 않으면 흐르지 않는다.
4. 아침 빵 자동 채우기를 없앤다. 빵은 구운 만큼만 있다. 대신 **집밥은 늘 먹을 수 있어** 굶는 벌은 없다(위기 없음, DESIGN 6).
5. 가꾸기에 **밭 일구기**를 더한다. 생산을 늘리는 플레이어의 손잡이다.
6. 저장 판을 2 로 올리고 판 1 을 읽어 옮긴다.

## 검토한 대안

| 대안 | 판단 |
| --- | --- |
| 시장 가판대와 사고팔기 | 화폐가 필요하다. 복잡한 경제는 DESIGN 8 이 뺀다 |
| 새 직업(방앗간지기·짐꾼) | 주민 20 명에서 직업을 늘리면 기존 직업이 얇아진다. 농부·제빵사가 직접 나르는 편이 인과가 보인다 |
| 작물을 밭 전체 한 값으로 | 칸마다 단계가 달라야 밭이 물결처럼 익어 가는 모습이 보인다 |
| 빵 부족 때 배고픔 벌 | 위기 없는 분위기와 맞지 않는다. 대신 빵집 빵은 즐거움을 조금 더 준다(기존) |

## 예상되는 결과

- 좋아지는 것: 길 위의 움직임에 목적이 생긴다(밀단·자루·생선·수레). 빵이 떨어지는 사건에 원인이 생긴다.
- 위험: 짐 나르기가 많아 걷는 비율이 다시 늘 수 있다(측정한다). 수치가 넉넉하면 부족이 안 생기고, 빠듯하면 빵이 늘 없다(시험으로 맞춘다).
