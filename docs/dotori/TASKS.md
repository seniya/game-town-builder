오너가 2026-09-26 로드맵과 방향을 에이전트에게 맡겼다. 이 문서는 에이전트가 정한 순서다.

### 게이트 VG1 — 가꾸는 마을

사람의 관찰로만 통과한다. 질문:

1. 빈 땅에 무언가를 놓고 싶어지는가. 놓는 조작이 쉬운가.
2. 목수가 목재를 날라 짓는 과정을 지켜보게 되는가, 지루한가.
3. 내가 놓은 벤치·꽃밭에서 주민이 쉬는 모습을 보았는가. 그때 기분이 어땠는가.
4. 새 주민이 이사 왔을 때 누구인지 궁금했는가.
5. 5 분 넘게 창을 켜 두고 들여다보고 싶었는가.

부정적이면 V2 로 가지 않는다. 콘텐츠를 더하지 않고 "보이는가(표현)" 와 "생기는가(규칙)" 를 나눠 고친다.

## 4. V2 분주한 마을 (SPEC 9, ADR 050)

밭에서 거둔 밀이 방앗간에서 밀가루가 되고, 제빵사가 밀가루를 날라 빵을 굽는다. 어부가 잡은 생선은 주점 저녁상이 된다.
**만든 것이 눈에 보이게 흐르는 것**이 목표다. 빵이 동나면 "밀가루가 모자라서" 라고 설명할 수 있어야 한다.

### 게이트 VG2 — 분주한 마을

1. 밀이 거둬져 방앗간·빵집으로 가는 흐름이 눈에 보이는가. 따라가 보고 싶은가.
2. 길에 짐을 나르는 사람이 늘어 마을이 더 살아 보이는가, 어수선한가.
3. 빵이 떨어졌을 때 이유를 알 수 있었는가.
4. 밭을 더 일구고 싶어졌는가.
