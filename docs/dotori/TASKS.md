### 게이트 VG1 — 가꾸는 마을

사람의 관찰로만 통과한다. 질문:

1. 빈 땅에 무언가를 놓고 싶어지는가. 놓는 조작이 쉬운가.
2. 목수가 목재를 날라 짓는 과정을 지켜보게 되는가, 지루한가.
3. 내가 놓은 벤치·꽃밭에서 주민이 쉬는 모습을 보았는가. 그때 기분이 어땠는가.
4. 새 주민이 이사 왔을 때 누구인지 궁금했는가.
5. 5 분 넘게 창을 켜 두고 들여다보고 싶었는가.

부정적이면 V2 로 가지 않는다. 콘텐츠를 더하지 않고 "보이는가(표현)" 와 "생기는가(규칙)" 를 나눠 고친다.

## 4. V2 이후 (VG1 뒤에 SPEC 으로 옮긴다)

- V2 분주한 마을: 밭의 밀이 자라고 거둬진다 → 수레로 방앗간 → 밀가루 → 빵집. 어부의 생선 → 시장 가판대. 짐꾼·수레.
  빵이 동나는 사건을 "생산이 모자라서" 로 설명할 수 있게 한다.
- V3 이야기: 주민이 기억하는 사건(첫 만남, 고백, 파티), 결혼과 한 집으로 이사, 생일, 주간 "도토리 신문" 요약.
- V4 큰 마을: 100 명·160 × 104 지도 후보. 틱 시간 계측 HUD, 원거리 주민 단순 모형·동작 멈춤, 경로 캐시.
- V5 계절과 소리.
